## 🚀 Featured Projects

### 🌱 Strawberry Plant Health Detection
**Computer Vision | PyTorch | YOLO | Edge AI**

Research on automated plant health detection using UAV imagery and proximal sensor data.

- Prepared 400+ image frames and 9,000+ annotations.
- Trained and compared YOLOv8, YOLO11, DETR, and Faster R-CNN.
- Evaluated models using precision, recall, F1, and mAP.
- Conducted preliminary deployment on NVIDIA Jetson Nano.

### 🏥 MIMIC Synthetic Data Generation
**Healthcare ML | Python | CTGAN | TVAE**

Synthetic clinical data generation and evaluation using MIMIC-III.

- Developed cleaning and synthesis workflows across 27 clinical tables.
- Explored CTGAN, TVAE, VAE, and Gaussian copulas.
- Compared synthetic and real data distributions.
- Evaluated downstream classification performance.

**NLP | Hugging Face | scikit-learn**

A modular retrieval-augmented question-answering system.
